# 13 Side Quest Template

Lighter than a world: no full-page transformation. One themed card/section per project.

## Structure (each side quest)
- Theme + accent color (from nearest world palette) + Biyoo costume
- Title as Quest name, 1-line claim [from 03, verified]
- 3 short bullets: problem, what I built, what I learned
- Proof links (repo, demo). If none, label "in design" and do not imply it is built.
- Optional 6-10s micro-animation (CSS/GSAP, no scroll scrub)

## Theme assignments (proposed)
| Project | Theme |
|---|---|
| Echo | Bleach: inner world, sword spirit speaks |
| Lumina Clinical | One Piece: Chopper's island, offline care |
| ReelClaim | Death Note: verdict stamp (only if status verified) |
| Others | pick per project; keep palette consistent |

## Upgrade path
A side quest becomes a full world only after Phases 0-4 are done and evidence is strong.
